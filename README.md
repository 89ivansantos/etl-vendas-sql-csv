ETL Vendas SQL → CSV

Automação ETL desenvolvida em Python para extração de dados de vendas diretamente do SQL Server, aplicação de validações e exportação dos dados para arquivos CSV.

📌 Sobre o projeto

O projeto automatiza o processo de extração e disponibilização de dados de vendas, reduzindo atividades manuais e garantindo maior padronização no processo.

O fluxo contempla:

- Conexão com banco de dados SQL Server
- Extração dos dados por meio de consulta SQL
- Validação das informações
- Exportação dos dados para CSV
- Registro de logs durante a execução
- Tratamento de erros e exceções
- Organização do processo de ETL

🔄 Fluxo do ETL

SQL Server → Extração → Validação → CSV → Log

🛠️ Tecnologias utilizadas

- Python
- SQL Server
- PyODBC
- Pandas
- CSV
- Logging
